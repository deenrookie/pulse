# Pulse 优化方案：快速复现、临时分享、AI 可扩展

日期：2026-09-16。此文记录首轮方案；随后用户明确要求完整分享、取消配额、延长有效期及改进 Intruder，已由 [当前验证与范围](Verification.md) 中的第二轮交付替代相关分享决策。基于 v0.3.7 实际代码，首期交付见 [Verification.md](Verification.md)。

## 产品判断

Pulse 最有价值的形态是**一个随时启动的本地流量调试工作台**。让开发者和安全工程师用很少的步骤抓到问题、复现请求、把必要证据交给同事，再用小插件补足特定业务需求。竞争力来自启动成本、工作流速度和可定制性；不以覆盖 Burp 的漏洞扫描、完整审计项目或大型扩展市场为目标。

已存在的优势应保留：Go 单二进制、浏览器即界面、本地持久化、流量虚拟列表、直接重放、可编辑报文、按需加载的 JavaScript 插件。已有 Intruder、拦截、HTTP/2、WebSocket 等能力继续服务现有用户，本期不扩大扫描和协议功能范围。

## 代码理解与方案依据

| 实际路径 | 当前行为 | 优化落点 |
| --- | --- | --- |
| cmd/pulse/main.go → proxy.Engine / api.Server | 单进程两个监听器，默认代理 8080、UI 8787；无 Rust/Tauri 工程 | 复用 UI 监听器提供分享，不引入服务或桌面壳 |
| proxy.executeRequest → store.Add/Update → SSE → state.ts | 捕获、插件、重写、拦截、转发，内存索引加 JSONL | 创建独立完成态快照，不订阅或公开整个流量列表 |
| api.Settings → settings.json → SettingsView | 当前 proxyAddr 是代理绑定地址；Remote instance 仅存浏览器配置 | 新增明确的 shareIP；链接端口使用服务端 UI 端口，避免误用代理端口或 Vite 地址 |
| api.Server.gate | 本地 Host 检查，非回环管理 API 需要访问密钥 | 分享令牌仅能读取一个快照；不能列流量、修改设置或执行插件 |
| internal/plugins + ExtensionsView | goja、SDK、在线编辑器、Check/Test、Mock、热加载、last-good 版本 | 提供一个可复用开发 Skill 和现有调试能力的入口，避免重造插件平台 |
| plugins_cli.go | check 可编译；test 夹具只读 method/URL/hook，不能完整断言结果 | Skill 提供标准库 Python 客户端，直接调用既有沙箱 API 并断言结果 |

早期 Product/Plugins 文档把已经实现的主动 HTTP、UI 面板等列为未来能力，容易误导 AI。本期同步修正文档；可执行模板与下载 SDK 直接从二进制内嵌资源生成。

## 首期范围与验收

### 1. 临时流量分享

核心场景：开发者选中一条完成请求，把请求/响应的可读证据临时交给同事查看。采用单条、静态、只读快照；这是在未收到范围问题回复时向用户说明的默认，不表述为用户已经确认。

路径：Settings → Temporary sharing 配置本机可达 IPv4/IPv6 → Live Traffic 选择请求 → Share → 查看接收者预览 → 设置有效期/是否含正文 → 创建并复制链接。Settings 列出活跃链接并可撤销。

- 链接是 `http://<shareIP>:<UI-port>/share/<192-bit-random-token>`，不包含实例访问密钥。
- 默认 30 分钟；界面提供 15/30/60 分钟、24 小时；API 接受 1–1440 分钟。到期自动释放副本，重启失效，不落盘。
- 默认不包含正文。清除 URL 用户信息、fragment、查询参数值；仅保留允许的通用请求头值，其余包括认证、Cookie、自定义头默认隐藏。错误细节和 WebSocket 帧不分享。
- 正文只有显式勾选才包含，并预览原文；路径和允许头仍可能含业务隐私，不能宣称完全自动脱敏。
- 独立静态 HTML 采用转义、无脚本 CSP、no-store/no-referrer，响应内容不会作为网页执行。
- 不自动公开 UI 监听器。使用 LAN IP 时需要以 `--ui 0.0.0.0:8787` 或对应 IPv6 监听启动；与显式绑定不匹配时阻止创建并说明操作方法。
- 单份 JSON 快照上限 2 MiB、同时 32 条、合计 16 MiB；超限明确拒绝。清空历史不撤销已经创建的独立快照；撤销或重启可清除。已保存的副本无法收回。

验收：配置持久化；链接使用设置 IP；接收者不用实例密钥可查看且不能操控实例；默认脱敏不影响原流量；正文显式包含；到期、撤销和重启后不可访问；并发和容量受控。

### 2. AI 插件开发 Skill

核心场景：用自然语言描述一个业务请求的修改规则，AI 获得准确的 Pulse API 契约，写出有作用域的插件，并用合成数据证明行为。

路径：Extensions → Plugins → Skills → 阅读/复制 SKILL.md，或下载完整 kit → AI 工具载入 → 编写插件 → Check/Test run → 查看结果 → Save → 本地真实请求验证。

交付一个 `pulse-plugin-dev` Skill：运行时契约、作用域限制、凭据与配置规范、错误/日志排查、目录项目边界；加上最小模板、正反夹具、SDK 类型和 Python 标准库断言客户端。源文件、页面与下载包同源，避免多份文档漂移。页面支持深链、刷新保留、失败提示、复制回退和手动选择。

验收：完整 kit 可从内嵌应用下载；脚本确实对 sandbox 返回字段做断言，runtime error 必须失败；按 Skill 可实现有 host/path 限定的插件并实测正反路径；页面一键进入现有编辑器并完成 Check/Test；不新增 npm/Go 运行依赖或 AI 云请求。

## 优先级与后续决策

| 优先级 | 内容 | 本次决定 | 继续投资的证据 |
| --- | --- | --- | --- |
| P0 | 分享一个问题请求，明确权限和失效 | 本期实现 | 同事能凭链接理解请求及响应，无须交出整个实例 |
| P0 | AI 插件编写和调试闭环 | 本期实现 | 模板与反例夹具可执行，沙箱及真实代理试用成功 |
| P0 | 捕获数据正确性与测试可信度 | 修复实测暴露的缓冲重复发送、元数据竞争、跨平台测试夹具错误 | 全量检查和针对性回归通过 |
| P1 | 多条请求组成一次问题证据 | 暂缓 | 单条快照不足以表达真实问题的重复反馈；届时设计选中范围与总量限制 |
| P1 | 增强插件 fixture/CLI 输出 | 暂缓，先复用 HTTP 沙箱 | 用户确需不启动实例进行完整断言或 CI 集成 |
| P2 | 实时协作、账号/工作区、云中转、插件市场 | 不进入本期 | 独立需求与明确运维/权限模型；不能用“等等”推导成全面平台扩张 |

衡量方式先用本地任务走查：从选中请求到拿到可打开链接的操作数、插件首次 Check/Test 成功率、错误提示是否能指导恢复。当前无用户量化基线，不能声称性能或转化已提升某个百分比。持续监控包大小、依赖数量和运行内存，只有出现实测瓶颈才做新的抽象或服务拆分。

## 界面与交互决策

复用现有按钮、卡片、主题 token；分享使用浏览器原生 dialog，提供焦点限制、Escape 和关闭后的焦点恢复。Skills 是插件内的次级页签。高频流量数据、源码预览、键盘导航不增加动效；无需新组件或动画库。

| Before | After | Why |
| --- | --- | --- |
| 分享弹窗初版使用固定深色背景，在 Linear 浅色主题中文字不清晰 | 改用 bg-panel/text/border-strong 主题变量 | 实机截图发现对比问题，修复后按主题复验 |
| 现有“复制流量链接”只能在拥有完整实例的控制台中打开 | 增加明确的 Share 按钮和独立接收者页面 | 区分本地导航与授权分享，避免将控制台密钥交给接收者 |
| 插件能力散落于编辑器与文档 | Skills 紧邻 Editor/Samples，提供完整 kit 和明确步骤 | AI 和人都能找到同一套运行契约 |

动效机会检查：未新增专属动画；拒绝为流量、源码和键盘页签切换增加移动。review-animations / improve-animations 本次增量没有高优先级动效整改项。apple-design 检查聚焦即时状态反馈、明确关闭、焦点恢复、字体可读性；保留稳定的信息布局。
