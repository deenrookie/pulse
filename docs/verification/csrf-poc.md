# CSRF PoC 生成 — 验证记录

对齐 Burp Suite「Engagement tools → Generate CSRF PoC」：右键任意请求生成一段让受害者浏览器自动发出该请求的 HTML（Cookie 不写入 PoC，由受害者浏览器自动携带）。

## 对齐 Burp 的行为

| Burp 行为 | Pulse 实现 |
| --- | --- |
| 右键请求 → Engagement tools → Generate CSRF PoC | Live Traffic 行右键、Live Traffic 请求面板右键、Repeater 标签右键、Repeater 请求编辑器右键，四个入口均为 `Generate CSRF PoC` |
| 生成 `history.pushState` + 表单 + 隐藏 input + 自动提交脚本（`document.forms[0].submit()`） | 相同模板，注释行为 `CSRF PoC - generated by Pulse` |
| GET：query 参数转隐藏 input，表单不写 method | 相同 |
| urlencoded POST：body 参数转隐藏 input，action 保留 query | 相同 |
| 其他 Content-Type（JSON 等）：表单 `enctype="text/plain"` 或跨域 XHR | Auto 选 XHR（精确复现方法/CT/体）；强制 Form 时走 text/plain 拆分技巧，JSON 无 `=` 时注入 `"x":"="` 占位对 |
| 选项：Include submit button / Auto-submit script | 均实现，XHR 技术下禁用（脚本本身即自动执行） |
| 上半面板可编辑请求 + Regenerate | 相同（RawEditor 编辑，Regenerate 重建） |
| 下半面板生成的 HTML 可编辑 | 相同（Copy/Save 用编辑后的内容） |
| 技术无法精确复现时显示警告 | 相同（Content-Type 无法设置、非 GET/POST 方法、CORS 预检、无 `=` 的非 JSON 体） |
| Test in browser | 本地 blob 页面新标签页打开；WebView 拦截弹窗时降级为下载文件并提示 |
| Cookie 不进入 PoC | 相同（XHR 带 `withCredentials = true`） |

## 实现位置

- 生成器（纯函数）：`web/src/components/csrf.ts`
- 对话框：`web/src/components/CsrfPocDialog.tsx`（样式 `theme.css` `.csrf-*`）
- 入口：`FlowTable.tsx` / `ProxyView.tsx` / `RepeaterView.tsx`（标签 + 编辑器）/ `MessageViewer.tsx`（RawView，请求侧）
- 全局事件 `pulse:generate-csrf-poc`（`{ raw, url }`，url 保留协议）由 `App.tsx` 挂载对话框

- 单元测试：`node web/test/csrf.test.ts` — **16 组全部通过**（GET/POST 表单、JSON→XHR、text/plain 拆分与 JSON 占位注入、PUT 降级、multipart→XHR、HTML 转义、选项组合、解析助手）。
- UI 回归（隔离实例 `--ui 127.0.0.1:8090`，内嵌生产构建）：`PULSE_TEST_API=http://127.0.0.1:8090 python scripts/verify-csrf-poc.py` — **11 项检查全部通过**：四个右键入口、urlencoded/JSON/GET 三种生成、技术切换、选项往返、编辑+Regenerate、剪贴板逐字一致、无页面错误。截图见 `gui-test-screenshots/csrf-*.png`。
- 真实操作验证（开发实例 + 浏览器实操）：Live Traffic 行/请求面板、Repeater 标签/编辑器四个入口实操通过；期间发现并修复 raw 往返丢协议（事件携带原始 URL）、选项闭包旧值（改为 effect 依赖）、HTML 面板过矮（布局再平衡：HTML 全显无需滚动、请求编辑器约 4 行）。
- `tsc --noEmit`、`vite build` 通过；生产构建下对话框布局复测（htmlFits=true）。

## 已知限制

- multipart/form-data 强制 Form 技术时无法重建 boundary —— Auto 会选 XHR 并带预检警告。
- Test in browser 在拦截弹窗的嵌入式 WebView 中降级为下载文件。
