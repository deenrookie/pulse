# Pulse 产品文档

> 版本：v0.1.0（MVP） · 状态：已实现 MVP 范围 · 维护者：Pulse Team

## 1. 产品定位

Pulse 是一款**运行于本地、通过浏览器操控的 Web 安全测试平台**（HTTP 抓包 / 改包 / 重放）。

一句话定位：**用现代 Web 技术重新实现的 Burp Suite / Caido 核心工作流**——Go 单二进制后端 + React 浏览器界面，开箱即用，跨平台。

| 维度 | 说明 |
| --- | --- |
| 产品形态 | 本地服务：Go 二进制同时提供 MITM 代理（默认 `:8080`）与 Web 控制台（默认 `:8000`） |
| 目标平台 | Windows / macOS / Linux（Go 交叉编译，无 CGO） |
| 目标用户 | Web 安全工程师、渗透测试人员、安全研究员、后端/前端开发调试 API |
| 核心价值 | 零安装门槛（单文件 + 浏览器）、实时流量可见、请求可拦截修改可重放、数据本地留存 |

### 1.1 与竞品的关系

对标产品为 PortSwigger **Burp Suite** 与 **Caido**。Pulse v0.1 聚焦两者最核心、使用频率最高的工作流（Proxy / Intercept / Repeater），以现代技术栈重实现：

| 能力 | Burp Suite | Caido | Pulse v0.1 |
| --- | --- | --- | --- |
| 形态 | 桌面 Java 应用（Swing） | Rust 后端 + Web UI | Go 后端 + Web UI（浏览器操控） |
| HTTP(S) MITM 抓包 | ✅ | ✅ | ✅ |
| 流量历史持久化 | ✅ 项目文件 | ✅ | ✅ JSONL 自动留存 |
| 拦截改包（Intercept） | ✅ | ✅ | ✅（请求级） |
| 重放（Repeater） | ✅ 多标签 | ✅ | ✅ 多标签，服务端持久化 |
| 消息检查器（Headers/Params/Hex） | ✅ | ✅ | ✅ Headers/Params/Pretty/Hex |
| WebSocket 隧道 | ✅ 可解析 | ✅ | ✅ 隧道级透传（帧级解析在路线图） |
| Intruder / 自动化攻击 | ✅ | ✅（Automation） | 🗓 路线图 |
| 插件/扩展生态 | ✅ BApps（Java/Python 等） | ✅（Rust/JS） | 🗓 路线图（Go plugin / 脚本钩子） |
| 协作 / 云端 | 企业版 | 云同步 | ❌ 非目标（见 1.4） |
| 上游代理链 | ✅ | ✅ | 🗓 路线图 |

### 1.2 设计原则

1. **单二进制、浏览器即界面**：下载即用，不需要安装桌面运行时；界面天然跨平台、可远程（SSH 端口转发）操控服务端实例。
2. **信息优先于装饰**：界面为高信息密度的深色工作台风格，动效只用于状态反馈（新流量、拦截到达），绝不干扰数据阅读。
3. **本地优先与隐私**：所有流量数据只落在本机数据目录，绝不外传；CA 证书不自动植入系统信任库，由用户显式安装。
4. **工作流连续**：History → 检查 → Send to Repeater / Intercept 的核心动线与 Burp 肌肉记忆兼容，降低迁移成本。
5. **YAGNI 迭代**：每个版本交付能用、可验证的最小核心，再按需扩展。

## 2. 核心概念

| 概念 | 定义 |
| --- | --- |
| **Flow（流）** | 一次完整的 HTTP 事务：请求 +（可选）响应 + 元数据（时间、耗时、来源）。是系统的核心数据单元。 |
| **Proxy（代理监听）** | 运行在本机的 MITM 代理监听器。浏览器/客户端将代理指向它后，所有 HTTP/HTTPS 流量经它转发并被记录为 Flow。 |
| **MITM（中间人解密）** | 对 HTTPS：Pulse 用本地 CA 动态为每个域名签发叶子证书呈现给客户端，同时以真实身份连接服务器，从而双方明文可见。需在客户端信任 Pulse CA。 |
| **Intercept（拦截）** | 开启后，匹配的请求在上游发送前被挂起进入队列；用户可查看/修改方法、路径、头、体，再 Forward 放行或 Drop 丢弃。 |
| **Repeater（重放）** | 将任意历史请求复制到独立的重放标签，任意修改后多次发送，响应即时对比。标签服务端持久化。 |
| **Inspector（检查器）** | 对请求/响应的结构化视图：摘要、Headers（保序保重复）、Params（Query/Cookie/Form）、Pretty（JSON 格式化）、Hex。 |
| **Scope（范围）**（路线图） | 目标域名集合，用于过滤噪音与聚焦测试范围。 |

## 3. MVP 功能范围（v0.1 已交付）

### 3.1 代理与抓包（Proxy）
- HTTP 与 HTTPS（CONNECT + MITM）流量捕获，含请求/响应头与正文（二进制安全，上限 10MB/消息，超限截断标记）。
- WebSocket / 任意 `Upgrade` 流量：完成 HTTP 升级握手后透明隧道转发（不解析帧）。
- 历史列表：实时（SSE 推送，无需刷新）、编号、时间、方法、Host、路径、状态码、内容类型、大小、耗时；关键字过滤；清空/单条删除。
- 流量持久化到数据目录 `flows.jsonl`，重启自动恢复。

### 3.2 拦截（Intercept）
- 全局开关（界面顶栏 + Intercept 页）。
- 请求到达后挂起进入待处理队列；界面展示并允许编辑：方法、URL、头（逐行）、正文。
- Forward（放行，可携带修改）/ Drop（丢弃，客户端收到 502）。
- 队列上限 50 条，超出自动放行最旧请求。

### 3.3 重放（Repeater）
- 从 History 任意流量 "Send to Repeater"，生成独立标签（服务端持久化，重启保留）。
- 标签内编辑完整请求（方法/URL/头/体）并多次发送；响应与请求一并展示。
- 重放产生的流量同样进入 History（来源标记 `repeater`）。

### 3.4 检查器（Inspector）
- 请求/响应两侧检查器：Headers、Params（Query/Cookie/Body Form）、Pretty（JSON 自动格式化）、Hex、Raw。
- 正文按 Content-Type 智能呈现：文本 / JSON 美化 / 图片预览 / 二进制 Hex。

### 3.5 证书与设置（Settings）
- 首次启动自动生成 CA（ECDSA P-256，10 年），界面提供 PEM 下载与 Windows/macOS/Firefox 安装指引。
- 显示监听地址、数据目录、流量统计、CA 指纹。

## 4. 用户体验设计

### 4.1 信息架构

```
┌──────────────────────────────────────────────────────────────┐
│ Pulse   [Proxy] [Intercept] [Repeater] [Settings]    ● 8080   │
├──────────────────────────────────────────────────────────────┤
│ 视图内容（见下）                                                │
└──────────────────────────────────────────────────────────────┘
```

- **Proxy**：上：流量表格（实时滚动，新行高亮渐隐）；下：左右分栏检查器（请求 | 响应）。
- **Intercept**：左：待处理队列；右：请求编辑器（方法/URL/头/体）+ Forward/Drop。
- **Repeater**：左：标签列表（可增删）；右上：请求编辑器 + Send；右下：响应检查器。
- **Settings**：证书下载与指引、运行信息。

### 4.2 关键交互约定
- 新流量到达：SSE 推送后表格追加一行，短暂高亮（无弹窗打扰）。
- 拦截到达：顶栏 Intercept 徽标计数 + 队列刷新；无模态阻塞。
- 所有破坏性操作（清空历史、删除标签）需二次确认。
- 键盘：表格上下移动选择；`Ctrl+Enter` 在 Repeater 发送。（更多快捷键在路线图）

### 4.3 视觉
深色工作台主题：近黑背景、等宽字体数据区、状态色仅用于语义（2xx 绿 / 3xx 蓝 / 4xx 橙 / 5xx 红）、单一强调色（青）。高对比、低彩度，保证长时间阅读舒适。

## 6. 非目标（v0.1 明确不做）
- 云端同步 / SaaS 多租户。
- 主动漏洞扫描器。
- 自动向系统信任库植入 CA（安全红线，始终由用户手动完成）。
- 桌面壳（Tauri 封装）暂不在本期交付范围，架构已预留（Web UI 与 API 天然可复用）。

## 7. 验收标准（MVP）
1. 配置浏览器代理指向 Pulse 后，HTTP/HTTPS 流量实时出现在 History，正文完整可查。
2. 开启 Intercept 后请求被挂起，可修改后放行（服务器收到修改后的请求）或丢弃。
3. 任意历史流量可 Send to Repeater，修改后重发成功并看到响应；重启后标签仍在。
4. 未安装 CA 时 HTTPS 抓包得到证书告警，安装后正常；CA 可从 Settings 下载。
5. `go test ./...` 全绿；前端 `tsc` 无错误、`vite build` 成功；真实浏览器走通 1–3。
